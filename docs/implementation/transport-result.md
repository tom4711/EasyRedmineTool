# Transport and cache remediation (#53, #54, #58)

Implemented in `EasyRedmineApiClient`, `TicketService`, and `TimeEntryFormDataCache` with unchanged public service signatures.

- Both list endpoints use one pagination loop. It advances by the records received, uses the response limit when no total is available, continues short server-reduced pages when a total remains, and reports an explicit `RedmineApiException` for an unexpected offset, repeated record IDs, an empty premature page, or the 100-page safety boundary. Existing view-model API-error paths can display the incomplete-fetch message.
- Time-entry `from` and `to` use the existing invariant Gregorian `RedmineDates.FormatSpentOn` helper.
- Both caches capture a generation, detach pending loads on invalidation, and only publish/remove in-flight state while that generation still owns it. Old callers may complete with their original response; new callers never share that response or its pending task. Lazy tasks registered under a lock prevent duplicate loader factory execution. A caller's cancellation only stops its own wait; shared GETs use `CancellationToken.None`.

TDD evidence: the first compiled targeted run failed 11 intended cases (four reduced-page cases, both safety bounds, th-TH, and four cache generation/cancellation cases). After implementation the targeted run passed **27/27**, no failures or skips. A subsequent progress regression reproduced two further failures when a server repeatedly returned its first page; a record-ID guard fixes that ambiguity (response offset zero can also mean omitted metadata). The final targeted plus existing TicketService suite passed **40/40**, no failures or skips. The old test expecting silent 10,000-item truncation now requires an explicit incomplete-fetch exception. Tests cover both endpoints at 25/80 with and without `total_count`, ordinary 100-row/empty final pages, all three date cultures, invalidation while old/fresh loads overlap, preservation of the new in-flight task after old completion, cache reuse, and independent waiter cancellation.
